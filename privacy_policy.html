Política de Privacidade

Última atualização: maio de 2026

O aplicativo Vistoria Fácil foi desenvolvido com o compromisso de proteger a privacidade dos seus usuários. Esta política descreve quais dados são coletados, como são utilizados e quais são os seus direitos, em conformidade com a Lei Geral de Proteção de Dados (LGPD — Lei nº 13.709/2018).

1. Dados coletados

O app coleta as seguintes informações:

  • Dados de conta: nome e endereço de e-mail, fornecidos no cadastro ou via login com Google.
  • Dados de vistoria: endereço do imóvel, data, nome do cliente e descrição dos cômodos e itens inspecionados.
  • Fotos: imagens dos itens do imóvel capturadas pela câmera ou selecionadas da galeria durante a vistoria.

2. Como os dados são utilizados

Os dados coletados são utilizados exclusivamente para:

  • Autenticar o usuário e manter a sessão ativa;
  • Armazenar e sincronizar as vistorias criadas pelo próprio usuário;
  • Gerar laudos em PDF das vistorias realizadas.

Não compartilhamos, vendemos nem utilizamos seus dados para fins de publicidade.

3. Armazenamento e segurança

Todos os dados são armazenados de forma segura nos serviços do Google Firebase (Authentication, Firestore e Storage), que adotam criptografia em trânsito (TLS) e em repouso. O acesso aos dados é restrito exclusivamente ao usuário proprietário de cada vistoria.

4. Serviços de terceiros

O app utiliza os seguintes serviços do Google:

  • Firebase Authentication — gerenciamento de login;
  • Cloud Firestore — banco de dados das vistorias;
  • Firebase Storage — armazenamento de fotos;
  • Firebase Crashlytics — registro anônimo de erros técnicos.

Esses serviços são regidos pela Política de Privacidade do Google.

5. Público-alvo

Este aplicativo é destinado a profissionais do mercado imobiliário e usuários maiores de 18 anos. Não coletamos intencionalmente dados de crianças menores de 13 anos.

6. Seus direitos (LGPD)

Você tem direito a:

  • Acessar os dados armazenados sobre você;
  • Solicitar a correção de dados incorretos;
  • Solicitar a exclusão da sua conta e de todos os seus dados;
  • Revogar o consentimento de uso dos dados a qualquer momento.
